## Banner-defect fix record (G0 605px-in-360px)

Root cause was the overflow chain around the banner, not the banner
itself (banner already had body `min-width:0` + wrapping actions):
`ConflictBanner` grid `auto 1fr auto` -> `auto minmax(0,1fr) auto` with
`min-width:0`/`max-width:100%`, message `overflow-wrap:anywhere`;
`DocumentEditor` header flex row wraps, title `flex:1 1 auto` +
`min-width:0`; `EntityList` fixed `280px 1fr` grid -> single column
under 720px; fixed flex minimums (SheetEditor 200px, RollAction/
FieldEditor 140px) -> 0; version-history table restacks to cards under
599px with a `versionOverlay` hook; `PreviewFrame` fixed 360/1280px
canvas -> `max-width:100%` + inner `overflow:auto` (was clipping
`hidden`); `PublishDialog` meta rows `120px minmax(0,1fr)`, stacked
under 399px; `SystemLibrary` rows wrap; character `dl` value column
`minmax(0,1fr)`. Scrollable tab strip (`overflow-x:auto`) kept: page
itself does not scroll.
