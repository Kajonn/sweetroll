# T2 component styles

Extend the same presentation record with optional `componentStyle: "default" |
"classic"`. Absence is Default. All three color presets support both styles;
unknown authored styles fail structural validation. Save, publication, export,
clone, campaign and cached character projections carry the complete selection.

Classic uses platform-authored CSS geometry and the local Georgia serif font for
headings, fine dividers, crisp panels, outlined item cards and resource controls.
It downloads no artwork or fonts. Colors remain independently composable. Shared
components retain their semantics, labels, disabled/loading/error states and
44 px targets. No extra renderer, navigation, rules, art recoloring or scripting.

The presentation context carries style to native and shared Radix portals. Style
changes update attributes/tokens in place and preserve live input, roll and
offline queue state. Validate the six combinations with the existing routed
journey and enlarged text, keeping human/device G9 acceptance separate.
