## CWD defect fix (Task 32 follow-up)

Task 32's reviewer flagged that `web/playwright.config.ts` `webServer` entries invoke `npm run migrate`, `npm run dev:http`, and `npm run web:dev` from the script's CWD. Playwright's default `webServer.cwd` is wherever `playwright test` was invoked from. `npm run web:test:e2e` (root) shells into `npm --prefix web run test:e2e`, which runs `playwright test` from `web/`. Root scripts (`npm run migrate`, etc.) resolve from the repo root, not from `web/`, so the `webServer` commands fail under the default invocation.

Fix applied: each `webServer` entry now declares `cwd: resolve(__dirname, "..")`, evaluated once at config load. This keeps the `npm run web:test:e2e` invocation pattern unchanged (no `package.json` edits) and localizes the fix to `web/playwright.config.ts`.

```ts
import { fileURLToPath } from "node:url";
import { dirname, resolve } from "node:path";

const __dirname = dirname(fileURLToPath(import.meta.url));
const repoRoot = resolve(__dirname, "..");

webServer: [
  { command: "npm run migrate && npm run dev:http", url: "http://localhost:3000/health/ready", reuseExistingServer: !process.env.CI, timeout: 60_000, cwd: repoRoot },
  { command: "npm run web:dev", url: "http://localhost:5173", reuseExistingServer: !process.env.CI, timeout: 60_000, cwd: repoRoot },
],
```

## `playwright-core` version pin

`@axe-core/playwright@4.10.0` declares `playwright-core >= 1.0.0` as a peer dep. Without a top-level constraint, npm resolved `playwright-core@1.62.1` (latest semver match) for axe-core while `@playwright/test@1.48.0` pinned `playwright-core@1.48.0` transitively. The two `Page` types are structurally divergent, so `new AxeBuilder({ page })` failed typecheck (`Type 'Page' is missing the following properties from type 'Page': ariaSnapshot, cancelPickLocator, …`).

Fix applied: `playwright-core@1.48.0` added to `web/package.json` devDependencies, forcing dedup (`npm ls playwright-core` confirms one hoisted instance). This matches the design's intent of a single Playwright version across the web workspace and unblocks the axe scan's typecheck without touching the spec body.
